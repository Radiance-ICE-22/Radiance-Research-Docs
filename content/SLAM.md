## A Survey on 3D Gaussian Splatting:[@chenSurvey3DGaussian2025]

[@keethaSplaTAMSplatTrack2024a] **SplaTAM**: Real-Time 3D Mapping. Produce the map real time by tracking the position and orientation of the camera in the environment using the already built model and add new details if they are not recorded in the map.

[@dengCompact3DGaussian2024] **Compact 3D Guassian Splatting for Dense Visual SLAM**, introduce a method to compress and reduce the amount of memory and storage used by 3DGS base SLAM. (Uses indexing.)

[@hongLIVGaussMapLiDARInertialVisualFusion2024] **LIV-GaussMap: LiDAR-Inertial-Visual Fusion for Real-time 3D Radiance Field Map Rendering** . Here using multimodal sensor fusion (LIDAR, IMU etc) author improves the accuracy of the model.

[@huCGSLAMEfficientDense2024] **CG-SLAM**: The over-fitting and anisotropy generated by techniques like SplatSLAM of the Gausians are reduced here. Basically filter out unwanted and unnecessary blobs being generated.

[@huangPhotoSLAMRealtimeSimultaneous2024] **Photo-SLAM**: A technique which uses 3DGS to produce photo-realistic mapping while having online learning the environment. The input is broken down into a Gaussian pyramid before the learning process. It progressively learn the features of the map.

[@jiNEDSSLAMNeuralExplicit2024] **NEDS-SLAM**: Uses a RGB-D (Color camera with each pixel having depth information. Depth camera basically.) SLAM framework to create a semantic classification based map. (Basically it can identify the objects in the environment.) It claims it makes the model more accurate than raw 3DGS. 

[@langGaussianLICRealTimePhotoRealistic2025] **Gaussian-LIC**: 3DGS + LIDAR and Inertial camera combined to give a accurate model. Here they dealt with  the issue of open spaces which 3dgs fails to handle. 
1. They scaled up the blobs with distance such that distant object doesn't affect closer ones.
2. They have set a boundary for the sky using world coordinate frame to set up a white color Gaussians.

[@liSGSSLAMSemanticGaussian2025] **SGS-SLAM**: Claims to be the first semantic visual SLAM system based on 3dgs.

[@matsukiGaussianSplattingSLAM2024a] **Gausian splatting SLAM**: Claims to be the first attempt incorporate 3dgs in SLAM. Has some method of Camera pose estimation and a novel Gaussian isotropic shape regularisation to ensure geometric consistency.

[@pengRTGSLAMRealtime3D2024] **RTG-SLAM**: A real time, less fidelity 3dgs SLAM method. Here RGB-D camera is used to tackle large scenes. They  force each Gaussian to be either opaque or nearly transparent.

[@sunHighFidelitySLAMUsing2024] **High-Fidelity SLAM**: RGB-D camera + 3dgs method. To tackle overfitting during observing the same objects(locations) they have introduce a regularization loss in the optimization.

[@tosiHowNeRFs3D2025] A survey on `How NeRF and 3DGS are reshaping SLAM`
